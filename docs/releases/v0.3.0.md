## Nouveautés

- **Quiz des océans** : les cinq océans, avec leurs limites tracées sur la carte.
- **Quiz des mers** : 52 mers du monde, à jouer par océan ou par région (Méditerranée, Europe du Nord, Asie du Sud-Est…).
- **Snap Store** : GeoLearner s'installe sur Ubuntu avec `sudo snap install geo-learner`.

## Installer

- **Windows** : [Microsoft Store](https://apps.microsoft.com/detail/9N1C5KFNMV7H)
- **Ubuntu** : [Snap Store](https://snapcraft.io/geo-learner), ou le fichier `.snap` ci-dessous
- **Autres distributions Linux** : le paquet `.flatpak` ci-dessous (`flatpak install --user geo-learner-0.3.0-x86_64.flatpak`), ou l'archive `.tar.gz` (`tar -xzf geo-learner-0.3.0-x86_64-linux.tar.gz -C ~/.local --strip-components=1`)
